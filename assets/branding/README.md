# Link icon base

`link-obd-icon-base.png` is the neutral high-resolution source for future
Link-family product icons. It intentionally contains no vehicle-manufacturer
mark.

To create a new product icon, preserve the complete base composition and place
only the manufacturer's emblem in the empty upper region. Keep the 16-pin
connector, dark rounded-square panel, blue trim, lighting, framing and scale
unchanged. The finished branded master belongs in the manufacturer repository;
Link retains only this neutral reusable base.

MBLink, JAGLink, FORDLink, BMWLink and AUDILink use this composition. Future
manufacturer faces must derive from the same neutral base.
